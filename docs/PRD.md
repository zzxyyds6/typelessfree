# typelessfree 产品需求文档（PRD）

**版本**：1.0
**日期**：2026-11-12
**项目名称**：typelessfree
**定位**：开源、免费、本地优先的 AI 语音输入工具，对标 Typeless，实现"按住说话 → 自动清理 → 直接插入当前光标"的体验。

---

## 1. 项目概述

typelessfree 是一款跨平台桌面语音输入工具。用户通过全局快捷键按住说话，系统在本地完成语音识别，可选进行 AI 文本清理（去除填充词、处理自我修正、自动标点与格式化），并将结果直接插入当前焦点应用的光标位置。

核心原则：

- 默认本地处理，音频不上传
- 完全免费，无订阅、无字数限制
- 开源可审计
- 体验接近商业产品 Typeless

---

## 2. 项目目标

1. 提供接近 Typeless 的"说完即得干净文字"体验。
2. 保证隐私：默认音频与文本均在本地处理。
3. 做到安装后即可用，配置简单。
4. 作为开源项目，便于社区贡献与二次开发。

---

## 3. 目标用户

- 需要高频写作、聊天、写代码注释的专业人士与开发者
- 重视隐私、不愿付订阅费的用户
- Windows / macOS / Linux 桌面用户（移动端作为后续扩展）

---

## 4. 功能需求

### 4.1 核心功能（MVP 必须实现）

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F1 | 全局快捷键触发 | 支持 hold-to-talk 与 toggle 两种模式，快捷键可配置 | P0 |
| F2 | 本地语音识别 | 使用本地 STT 模型（Whisper / Parakeet 等），支持 GPU 加速与 CPU 回退 | P0 |
| F3 | 实时预览 | 录音过程中显示浮动卡片与实时 partial 结果 | P0 |
| F4 | AI 文本清理（可选） | 去除填充词、处理自我修正、自动标点、列表格式化；可完全关闭 | P0 |
| F5 | 自动插入文本 | 结果自动粘贴到当前焦点应用光标位置，并支持恢复原剪贴板 | P0 |
| F6 | 个人词典 / 热词 | 支持添加专有名词、人名、术语，提高识别准确率 | P1 |
| F7 | 语言支持 | 支持自动检测或指定语言，至少覆盖中英文 | P0 |
| F8 | 基础设置界面 | 快捷键、模型选择、清理开关、词典管理 | P0 |

### 4.2 增强功能（后续迭代）

- 按应用自动调整语气/风格
- 选中文字后语音指令编辑（缩短、改语气、翻译等）
- 翻译模式
- 历史记录与搜索
- 跨设备同步（可选）
- 移动端键盘形态（Android / iOS）

---

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 隐私 | 默认音频不离开设备；清理阶段仅在用户开启时发送文本；无强制账号、无遥测或可关闭 |
| 性能 | 短句（GPU）目标延迟 <1 秒；长句可接受 2–5 秒 |
| 易用性 | 安装后几乎零配置即可使用；首次启动引导清晰 |
| 兼容性 | 支持 Windows 10/11、macOS（Apple Silicon + Intel）、主流 Linux 发行版 |
| 可扩展性 | 配置文件清晰，支持自定义模型路径、API 端点、提示词 |
| 许可 | MIT 或 Apache-2.0 |

## 6. 技术建议

- **桌面框架**：优先 Tauri（Rust + Web 前端，轻量）；也可用 Python 快速原型
- **语音识别**：faster-whisper / whisper.cpp / NVIDIA Parakeet
- **热键与输入模拟**：pynput 或系统无障碍 API
- **AI 清理**：本地 LLM（Ollama）或任意 OpenAI 兼容 API
- **配置**：JSON + 简单 GUI
- **UI**：系统托盘 + 录音时浮动预览卡片

---

## 7. 可参考的开源项目

1. **Handy**（github.com/cjpais/Handy）— 目前最成熟的全平台本地语音输入方案，MIT 许可，完全免费，支持 Whisper / Parakeet，可选 AI 清理。推荐作为主要参考架构。
2. **typeless-but-free**（github.com/AgentGameLab/typeless-but-free）— 明确对标 Typeless 的项目，本地 faster-whisper + 可选 LLM 清理，实时预览，支持学习用户修正。适合作为功能与交互参考。
3. **OpenWhispr**（github.com/OpenWhispr/openwhispr 或相关仓库）— 跨平台，支持本地 + BYOK 云端混合模式。功能较全，可作为增强功能参考。
4. **FluidVoice / VoiceInk** — 主要面向 macOS，本地模型 + AI 润色体验较好。适合参考 Mac 端交互与清理逻辑。
5. **ochre** 等新兴项目 — 可参考唤醒词、精炼模型等方向。

## 8. 开发优先级建议

**第一阶段（MVP）**

- 全局快捷键 + 本地 STT + 实时预览 + 自动插入
- 可选 AI 清理（支持关闭）
- 基础设置与个人词典
- 支持 Windows + macOS

**第二阶段**

- Linux 支持完善
- 按应用风格调整
- 历史记录
- 更好的模型管理与性能优化

**第三阶段**

- 移动端
- 更智能的上下文理解与个人风格学习
- 插件/扩展机制

---

## 9. 成功标准

- 用户安装后 5 分钟内可完成第一次有效输入
- 日常短句体验接近或优于系统自带语音输入
- 社区能较容易贡献模型支持、热词、快捷键配置等
- 保持完全免费与本地优先的核心承诺
