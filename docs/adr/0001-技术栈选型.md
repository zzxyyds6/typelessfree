# ADR-0001：技术栈选型

- 状态：已接受
- 日期：2026-11-12
- 关联 Issue：[#2](https://github.com/zzxyyds6/typelessfree/issues/2)

## 背景

PRD（`docs/PRD.md` 第 6 节）给出两条候选路线：

1. **Tauri（Rust + Web 前端）**：轻量、原生性能、打包体积小
2. **Python 快速原型**：生态丰富（faster-whisper），开发速度快

主要参考项目 [Handy](https://github.com/cjpais/Handy) 采用 Rust/Tauri 技术栈，功能场景与本项目高度重合（全局热键、本地 STT、可选清理、光标插入）。

## 决策

采用 **Tauri 2 + Rust** 作为 MVP 技术栈。

### 各层选型

| 层 | 选型 | 理由 |
|----|------|------|
| 桌面框架 | Tauri 2 | 轻量（安装包小）、Rust 生态、跨平台（Win/macOS/Linux） |
| 语音识别 | whisper.cpp（经 `whisper-rs` 绑定） | 纯 C++ 实现、无 Python 运行时依赖、支持 CUDA/Vulkan GPU 加速 |
| 全局热键 | `global-hotkey` crate | 跨平台热键注册，Tauri 生态常用 |
| 输入模拟 | `enigo` crate | 跨平台键盘/剪贴板模拟，用于光标插入 |
| AI 清理 | HTTP 调用 Ollama / OpenAI 兼容 API | 用户自选，BYOK，默认关闭 |
| 前端 | Vite + TypeScript（无重框架） | UI 简单（托盘、预览卡、设置页），无必要引入 React/Vue |
| 配置 | JSON 文件 + Tauri 设置窗口 | 符合 PRD 可扩展性要求 |

### GPU 加速策略

- Windows：CUDA（如可用）→ Vulkan → CPU 回退
- macOS：Metal（whisper.cpp 原生支持）
- Linux：CUDA / Vulkan / CPU

## 被否决的备选方案

### Python 原型（faster-whisper + pystray + pynput）

- **优点**：faster-whisper 生态成熟、开发快
- **否决理由**：发布需打包 Python 运行时（体积大、易踩版本坑）；跨平台全局热键与输入模拟在 Python 下兼容性问题多；MVP 用 Python 后大概率需用 Rust 重写，产生双倍工作量。faster-whisper 的核心优势（CTranslate2 加速）在 whisper.cpp + GPU 下可对等替代。

### Electron

- 体积大、内存占用高，与"轻量桌面常驻工具"定位不符，否决。

## 后果

- 本机与 CI 均需 Rust 工具链（CI 通过 GitHub Actions 自动提供）
- 模型下载与 whisper.cpp 编译产物管理需要在 F2（#4）中设计
- 后续若需 Parakeet 模型，可经 ONNX Runtime 引入，不阻塞 MVP
